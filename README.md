# Tugas HTML SMS 3

Tugas latihan HTML yang membahas penggunaan:

- HTML List (`<ol>`, `<ul>`, `<li>`)
- Link dan gambar
- IFrame
- Menampilkan website dan file HTML lain
- Menampilkan video YouTube

## Cara Menjalankan

Gunakan **Live Server** atau **Live Preview** di Visual Studio Code.

Buka file `index.html`,`index2.html` kemudian jalankan menggunakan extension tersebut.

> Pastikan koneksi internet aktif untuk menampilkan website dan video dari IFrame.
